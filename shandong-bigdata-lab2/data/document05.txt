A search engine is a web search engine designed to carry out web searches. It searches the World Wide Web for information about a specified topic in a systematic way. The results are usually presented as a list of links with short snippets. A search engine maintains an index of keywords and a set of hyperlinks contained in web documents. Behind every query, the engine tokenizes the words, removes stop words, looks the remaining terms up in the inverted index, ranks the matching documents with algorithms such as PageRank or TF IDF, and returns the top results. Modern search engines also use machine learning to understand intent and personalize results, and they must re index billions of pages continuously as the web changes.
