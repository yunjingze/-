Linux is a family of open source Unix like operating systems kernel distributed under the Linux kernel. It is one of the most prominent examples of free and open source software. Linux typically runs on servers and powers the majority of the cloud, because it is stable, secure, and highly configurable. A Hadoop cluster is usually deployed on Linux nodes: administrators create a dedicated account, disable firewalls for the test cluster, configure password free SSH between nodes, install the Java Development Kit, and edit core site xml, hdfs site xml, and mapred site xml to start the name node and data daemons. Common distributions used for teaching big data are Ubuntu and CentOS.
