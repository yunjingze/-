Big data is data that is too large, too fast changing, or too diverse to be captured, stored, and processed with traditional software tools within a tolerable time. Its characteristics are often described as volume, velocity, variety, and veracity. Big data analysis uncovers hidden patterns, correlations, and market insights by moving through and clustering disparate data sets rapidly. Technologies associated with big data include Hadoop, Spark, NoSQL databases, distributed file systems, and stream processing platforms. Common applications include recommendation systems, fraud detection, network security, ad targeting, and scientific discovery. As more devices and services generate logs and telemetry, the size of world data storage keeps growing every year.
