Apache Hadoop is an open source framework that allows distributed processing of very large data sets across clusters of computers using simple programming models. A Hadoop application can work in parallel on clusters of thousands of commodity computers, each with local storage and compute capability, without requiring a supercomputer. Hadoop stores data on top of the Hadoop Distributed File System, and processes it with the MapReduce programming model. The Hadoop ecosystem now includes many related projects, such as Hive for data warehousing, HBase for column oriented storage, Pig for data flow scripting, and Spark for in memory processing. Hadoop was inspired by earlier Google papers that described the Google File System and the MapReduce model. It is widely used for log analysis, recommendation systems, and large scale data mining.
