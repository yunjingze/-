MapReduce is a programming model and an associated implementation for processing and generating big data sets with a parallel, distributed algorithm on a cluster. A MapReduce program is composed of a map procedure that performs filtering and sorting, and a reduce procedure that performs a summary operation. The framework distributes the map tasks across worker nodes, shuffles the intermediate key value pairs, and then runs reduce tasks that aggregate the values for each key. This model hides the details of parallelization, fault tolerance, and data distribution from the programmer. MapReduce is a good fit for building inverted indexes, because counting word occurrences in documents can be split into independent per document tasks and then merged by word. Hadoop provides a Java implementation, while libraries such as mrjob offer the same idea through Python.
