Apache Spark is a unified analytics engine for large scale data processing. It provides high level APIs in Java, Scala, Python and R, and an optimized query engine for workloads that support batch and stream processing. Spark is usually many times faster than traditional Hadoop MapReduce for data warehouse workloads, because it keeps working data in memory and uses a more general execution model. Core concepts of Spark are resilient distributed datasets and the DataFrame API. Spark includes libraries for SQL, machine learning, graph processing, and streaming. Like MapReduce, Spark applications express computation as transformations and actions over distributed data, and the engine plans, optimizes, and schedules the work across the cluster.
