An inverted index is an index structure that maps content, such as words or numbers, to its locations in a database, document, or a set of documents. It is the most popular data structure used in document retrieval systems, full text search engines, and search engines in general. A term level inverted index stores a list of documents, together with the frequency of each term. This is a key value mapping from term to postings. Building an inverted index involves several steps: crawling and collecting documents, tokenizing text into terms, removing stop words, performing stemming, and finally sorting and merging postings. With an inverted index, a search engine can find every document containing a query term in constant time, instead of scanning the whole corpus.
